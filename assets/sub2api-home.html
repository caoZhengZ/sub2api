Quick start

三步，把请求接到正确的上游。

不需要重写业务逻辑。先拿到 Key，再把 Base URL 换到你的 LargeChestnut 站点即可开始。

01

创建账号与 API Key

登录控制台，在密钥页面创建独立 Key，并为不同项目设置备注、限额与可用分组。

02

设置 Base URL

在现有 SDK、客户端或环境变量中，把上游地址改为你的 LargeChestnut 域名，常用路径为 /v1。

03

选择模型并开始调用

从模型广场确认可用模型与分组价格，然后发起第一次请求；之后可在用量页查看 Token 与费用明细。

FAQ

开始之前，你可能想知道。

这里整理的是接入与使用层面的常见问题，具体模型、价格和支付方式以你的站点配置为准。

现有的 OpenAI / Anthropic SDK 可以直接使用吗？

通常可以。保留原有 SDK 和业务代码，把 Base URL 改为你的 LargeChestnut 地址，并使用站点生成的 API Key。Anthropic 客户端一般使用站点根地址，OpenAI 兼容客户端通常使用 /v1；请以站点说明为准。

模型和价格在哪里查看？

登录后打开模型广场，可以查看当前可用模型、所属分组、倍率与价格信息。实际可调用模型取决于站点已配置的渠道与账号池。

请求是如何分配到上游账号的？

LargeChestnut 会根据可用性、请求特征与调度策略选择上游账号，并支持粘性会话、并发限制、速率限制和必要的故障切换。这样可以减少手工切换与重复配置。

API Key 怎么计费？余额和用量在哪里看？

平台按实际请求的 Token 用量与模型倍率计费。登录控制台后，可在用量与账单页面查看余额、消费记录、请求明细和订阅配额。

支持哪些充值方式？

项目支持接入易支付、支付宝官方、微信官方与 Stripe 等渠道，也支持兑换码与订阅套餐。你的站点最终开放哪些方式，以支付配置和充值页面为准。

适合个人开发者还是团队运营？

两者都适合。个人开发者可以用统一入口管理多个模型与 Key；团队或平台运营者可以使用账号池、用户与分组、并发限制、计费、订单和审计能力搭建完整的分发体系。
